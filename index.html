¡Hola, soy Diana!

Soy desarrolladora Java Full Stack Jr. en formación con experiencia previa en comunicación digital y estrategia de contenidos. Durante los últimos años trabajé creando estrategias digitales, coordinando equipos editoriales y desarrollando contenido para proyectos de comunicación. Actualmente formo parte del bootcamp de Java Full Stack de Generation México, donde desarrollo proyectos colaborativos utilizando HTML, CSS, JavaScript, Bootstrap, Git y Java mientras continúo fortaleciendo mis habilidades para crear aplicaciones web. Mi objetivo es combinar mi experiencia en comunicación con el desarrollo de software para construir productos digitales claros, funcionales y centrados en las personas.
